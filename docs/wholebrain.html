这本书准备做什么

本书以整合为贯穿框架，将左右脑、上下脑、记忆、自我与人际关系联结起来，提出12种亲子互动方法。它关注的既是渡过当下冲突，也是借日常互动培养反思、自我调节和关系能力。最便于应用的主线是：先理解孩子当时的状态，再选择沟通方式，最后回到规则与修复。

阅读结构：全方位了解儿童思维的发展方式：帮孩子整合大脑 → 改善孩子的情绪：整合左右脑 → 教会孩子自我控制：整合上下脑 → 给孩子建立完整的心理拼图：整合记忆 → 让孩子更具有专注力：整合自我 → 培养孩子的人际技巧：整合自我与他人
